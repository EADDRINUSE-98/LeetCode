My follow-up on your third point was that this reason didn't match your choice. Starting at index 0, a single-element array runs the body once and still returns 0, so your `len(prices) == 1` guard isn't needed.

**Your final code:**

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        min_price_recorded_day = max_profit_recorded = 0
        for current_day in range(len(prices)):
            if prices[current_day] <= prices[min_price_recorded_day]:
                min_price_recorded_day = current_day
                continue
            max_profit_recorded = max(
                max_profit_recorded,
                prices[current_day] - prices[min_price_recorded_day],
            )
        return max_profit_recorded
```
